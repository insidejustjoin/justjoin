# GCPコスト最適化（手動実施ガイド）

## ⚠️ 現在の状況

gcloud CLIコマンドでVPCコネクターの更新にエラーが発生したため、**GCPコンソールから手動で実施する方法**をご案内します。

## ✅ 実施可能な最適化（安全）

### 1. VPCコネクターの最適化 ⭐ 最大の削減効果

**削減効果: 約1,500-2,000円/月（約17-23%削減）**

#### GCPコンソールからの実施方法

1. **GCPコンソールにアクセス**
   - https://console.cloud.google.com/ にアクセス
   - プロジェクト `justjoin-platform` を選択

2. **VPC Access に移動**
   - 左側のメニューから「VPC Access」を選択
   - または、検索バーで「VPC Access」を検索

3. **コネクターを選択**
   - `justjoin-vpc-connector` をクリック

4. **編集をクリック**
   - 右上の「編集」ボタンをクリック

5. **最小インスタンス数を変更**
   - 「最小インスタンス数」を `2` から `0` に変更
   - 「最大インスタンス数」は `10` のまま
   - 「保存」をクリック

6. **変更の確認**
   - 数秒待って、設定が `min-instances=0` に変更されたことを確認

#### 影響について

✅ **サービスへの影響: 最小限**
- サービスは継続して動作します
- Cloud SQLへの接続も正常に動作します
- コールドスタート時に数秒の遅延が発生する可能性がありますが、通常は問題ありません

#### 元に戻す方法

もし問題が発生した場合、以下の方法で元に戻すことができます：

1. GCPコンソールから同じ手順で「最小インスタンス数」を `0` から `2` に戻す
2. または、以下のコマンドで確認:
   ```bash
   gcloud compute networks vpc-access connectors describe justjoin-vpc-connector \
     --region=asia-northeast1 \
     --project=justjoin-platform \
     --format="value(minInstances)"
   ```
