## 登録者数増加に伴うコスト増加

### スケーリング要因

1. **Cloud Storage（録画ファイル）**
   - 1面接 = 約10問 × 平均20KB = 約200KB/面接
   - 100面接/月 = 約20MB/月
   - 1,000面接/月 = 約200MB/月
   - 10,000面接/月 = 約2GB/月
   - **コスト増加**: 約$0.046/GB/月

2. **Cloud Run（処理時間）**
   - リクエスト数に比例して増加
   - CPU/メモリ使用時間に応じて課金
   - **コスト増加**: 使用量に比例（リクエスト1,000回/月 = 約$0.40）

3. **Cloud SQL（データベース）**
   - データ容量は10GBまで固定（現在は数MB程度）
   - **コスト増加**: 10GB超過後、約$0.17/GB/月

## コスト最適化の提案

### 1. Cloud Runの最適化
```bash
# 最小インスタンス数を0に設定（既に設定済み）
gcloud run services update justjoin \
  --min-instances=0 \
  --region=asia-northeast1
```

### 2. 古い録画の自動削除
- ✅ 既に実装済み（面接開始時に古い録画を削除）
- 保存期間を制限（例: 90日）することでストレージコストを削減

### 3. Cloud Storageのライフサイクル管理
```bash
# 90日以上経過した録画を自動削除
gsutil lifecycle set lifecycle.json gs://justjoin-platform-match-job-documents
```

### 4. Cloud SQLの最適化
- 現在は最小構成（db-f1-micro）
- 10GBのストレージ容量があるため、しばらくは問題なし
- データが増加したら、適切なタイミングで容量を追加

### 5. 録画ファイルの圧縮
- 現在は約20KB/録画
- 必要に応じて圧縮率を上げる（ただし音質への影響を考慮）
